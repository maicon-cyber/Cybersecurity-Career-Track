### 🛠️ Projetos & Automações Desenvolvidas

#### 1. Monitor de Integridade de Arquivos (Python)
* **Arquivo:** `verificador_integridade.py`
* **Descrição:** Script focado em segurança defensiva que calcula o hash criptográfico SHA-256 de diretórios sensíveis. Gera uma linha de base em formato JSON e valida se houve qualquer modificação, adição ou deleção não autorizada de arquivos no sistema.

#### 2. Rotina Automatizada de Backup com Logs (Bash)
* **Arquivo:** `backup_sistema.sh`
* **Descrição:** Ferramenta utilitária essencial para a rotina de um Analista de Suporte/Sistemas. Ele realiza a compactação segura em formato `.tar.gz` de diretórios e alimenta um arquivo de histórico local (`backup_status.log`) registrando tags de `[SUCESSO]` ou `[ERRO]` com marcas de tempo.

#### 3. Auditoria Local Automatizada do Sistema (Bash)
* **Arquivo:** `auto_audit.sh`
* **Descrição:** Script que extrai métricas vitais do sistema operacional em tempo real, gerando relatórios instantâneos sobre portas de rede em escuta (`listening`), usuários ativos no terminal e status detalhado do consumo de Memória e Swap.

#### 4. Esteira de Versionamento Automático via SSH (Bash)
* **Arquivo:** `auto_push.sh`
* **Descrição:** Automação interna que otimiza o fluxo de trabalho diário, detectando modificações locais no repositório, realizando commits automáticos com carimbo de data/hora e enviando as atualizações para o GitHub de forma segura via chaves SSH.
